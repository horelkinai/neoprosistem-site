## Мобильное меню (слайд-панель) — как устроено

Реализовано в `css/styles.css` (медиа `max-width: 1024px`) и `js/main.js` (блок «Мобильное меню»):

- **Вид**: панель `width: min(340px, 88vw)` фиксированная справа, `transform: translateX(110%)` в закрытом состоянии; при открытии плавно выезжает (`.main-nav.open`). Сверху заголовок «МЕНЮ», пункты с ховером, снизу по желанию CTA-кнопка.
- **Оверлей**: `.nav-overlay` затемняет контент (`backdrop-filter: blur(2px)`, z-index 95), клик по нему закрывает меню.
- **Z-index-стек**: шапка `100` → панель меню `96` → оверлей `95` → лайтбокс сертификата `1000`. Не менять без проверки.
- **Блокировка скролла**: `body.menu-open { overflow: hidden; }`.
- **JS-логика**: `setMenu(open)` — переключение классов; `moveNavForMobile()` — на экранах ≤1024px `<nav>` переносится в `<body>`, на десктопе возвращается в `.header-inner` перед `.header-cta` (иначе `backdrop-filter` шапки «съедает» `position: fixed`); `syncDrawer()` — подгоняет `top`/`height` панели под высоту шапки. Закрытие: Esc, клик по оверлею, клик по ссылке меню, ресайз >1024px.
- **Проверено** (Playwright, 390×844): панель от низа шапки до низа экрана, горизонтального скролла нет, закрытие работает, ошибок консоли нет.

Правки меню в `js/main.js`/`css/styles.css` автоматически действуют на все страницы (шапка общая), перегенерация подстраниц не нужна.

## Контактная панель + ИИ-ассистент

Добавлено 08.08.2026 по запросу клиента («контакты ссылки и прочее сбоку, а ещё ИИ-агента по вопросам»). Разметка продублирована **вручную** во все 5 страниц (блок перед `<script src="js/main.js">`), т.к. `tools/gen_pages.py` сломан.

- **`.contacts-rail`** — фиксированная вертикальная панель справа по центру экрана (`position: fixed`, `z-index: 80`): Telegram, Instagram, телефоны BY/RU, CTA «Бесплатная диагностика» (`#diagnostics`). Скрыта на экранах ≤1024px, чтобы не пересекаться с мобильным меню.
- **`.ai-chat`** — виджет «ИИ-ассистент»:
  - `.ai-chat-launcher` — плавающая кнопка (`fixed`, `z-index: 85`): десктоп — справа снизу (right 22px, bottom 90px), мобильный — круглая 58px, bottom 16px.
  - `.ai-chat-window` — окно чата (`fixed`, right 22px, bottom 150px, `z-index: 85`, `max-height: calc(100dvh - 320px)`); на ≤1024px — почти весь экран, bottom 86px (над бургером).
  - Шапка окна, тело с сообщениями, **чипы быстрых вопросов** (`data-q`: Цены / Метод / Как начать / Контакты), форма ввода, футер с контактами.
- **JS (`js/main.js`, блок «ИИ-ассистент» после лайтбокса)**:
  - `AI_KB` — локальная база знаний (~10 тем: цены, метод, направления, диагностика, этапы, контакты, основатель, результаты, приветствие/прощание). **Ответы локальные, без внешнего API** — это не настоящий LLM.
  - `normalize()` — нормализация запроса: важно, что НЕ используется `\w` (в JS не матчит кириллицу) — используется `[^а-яёa-z0-9\s\-+@]`.
  - `findAnswer()` → `aiSend()`: поиск по ключевым словам, typing-индикатор `.ai-typing`, fallback «Не нашёл точного ответа…» с предложением написать в Telegram.
  - Закрытие: крестик или Esc.
- **Проверено** (Playwright): открытие/закрытие на десктопе и мобильном, ответы на чипы и на «Сколько стоит диагностика?», fallback, горизонтального скролла нет (1280 и 390), ошибок консоли нет.

Правки в `css/styles.css` и `js/main.js` действуют на все страницы, но **HTML-блок** `.contacts-rail`/`.ai-chat` нужно дублировать во все 5 файлов вручную.
